What gets measured

  • HTTP (both modes): throughput, p50/p95/p99, error taxonomy, per-route and per-phase breakdown, health availability.
  • Language runtimes (both modes): installed host PHP, Python, Node, Rust and Spid3r variants, checksum-verified.
  • Deliverable: a single-file HTML report with inline SVG charts, no JavaScript, no CDN.

The tool never changes container configuration, memory limits, or application code. It only sends GET requests and reads cgroup counters when Docker is selected. Always use a non-production target first.
