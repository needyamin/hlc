What gets measured

  • HTTP: throughput, p50/p95/p99, error taxonomy, per-route and per-phase breakdown.
  • Container: cgroup v2 memory.stat anon in raw bytes, memory.current, CPU from cpu.stat, PSI, OOM kills, PIDs, restarts.
  • Recovery: a zero-load cooldown and a 1 Hz availability re-probe separate a retained allocator high-water mark from a true unbounded leak.
  • Deliverable: a single-file HTML report with inline SVG charts, no JavaScript, no CDN.

The tool never changes container configuration, memory limits, or application code. It only sends GET requests and reads cgroup counters. Always use a non-production target first.
